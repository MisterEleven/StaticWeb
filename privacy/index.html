Hosting and request data

The site is hosted on GitHub Pages and delivered through Cloudflare. Opening a page sends network requests to the delivery infrastructure, including an IP address and technical request information needed to deliver and protect the site.

GitHub documents that Pages visitors’ IP addresses are logged and stored for security purposes, whether or not visitors are signed into GitHub. Cloudflare processes traffic and network information for delivery and security. Provider processing can take place outside Switzerland.

See the GitHub privacy statement and Cloudflare privacy policy for provider practices. No site-specific log-retention period is asserted here. The site is not anonymous merely because it has no analytics.

Analytics, cookies and browser storage

The project index and Bern Heat Islands guide do not include publisher-installed analytics, advertising pixels, account registration or data-submission forms. Their map sliders, search and review controls run locally in the browser. The review viewer loads its image tiles and JSON from this site.

The publisher does not set application cookies on those pages. Hosting and security infrastructure can process request data and may apply provider-managed security mechanisms; this statement does not promise that the delivery layer never uses cookies.

The legacy portfolio page stores an interface preference in localStorage on the visitor’s device. Clearing site data removes it. This is separate from server-side request logs.

Fonts and project-specific external services

Fonts on the current project index and Bern guide are served from this site. Their upstream SIL Open Font License notices are available for Fraunces, Inter, JetBrains Mono and the fonts listed in the guide source register.

Other project and legacy pages may load fonts from Google Fonts and interactive 3D libraries or decoders from Google-hosted resources, cdnjs/Cloudflare or jsDelivr. Those requests disclose normal connection information to the respective provider. On interactive 3D pages, optional augmented-reality controls may hand off to the device’s viewer after the visitor chooses them.

Provider information: Google, Cloudflare/cdnjs and jsDelivr. Following an external project, source or social link leaves this site and is governed by that destination’s practices.

Research images, geodata and reuse

Bern Heat Islands combines swisstopo imagery and landscape/surface/terrain products with the City of Bern’s modelled PET data. Source copyrights and attribution conditions continue to apply to derived images. The source and reuse register identifies products, transformations and terms; this site does not assign a blanket Creative Commons licence to mixed-source material.

Published maps are research visualisations, not official planning, health or emergency advice. PET is a modelled heat-stress index, not a direct air-temperature measurement. Predictions and error maps have experimental limitations documented in the guide.
